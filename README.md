# devops-prep

Plan de estudio de 11 semanas para pasar a DevOps Engineer, de Linux y Bash a
un proyecto integrador con Kubernetes, Terraform y CI/CD.

Por ahora el repositorio contiene solo el plan; el trabajo de cada semana se
irá agregando aquí.

## Plan

| Semana | Tema |
|--------|------|
| 01 | Linux profundo + Bash scripting |
| 02 | Python para automatización + Git + Networking |
| 03 | Docker |
| 04 | AWS fundamentals + Cloud Practitioner |
| 05 | Terraform (IaC) |
| 06 | Kubernetes fundamentals |
| 07 | Helm + EKS |
| 08 | CI/CD con GitHub Actions |
| 09 | Observabilidad (Prometheus + Grafana) |
| 10 | Ansible + Seguridad |
| 11 | Proyecto integrador |

## Stack objetivo
`Linux` `Bash` `Python` `Docker` `Kubernetes` `Terraform` `AWS` `GitHub Actions` `Prometheus` `Grafana` `Ansible`

Inicio: abril de 2026.
